Event-driven fraud alerting. A REST API queues each transaction on JMS and responds immediately, so intake stays fast even when fraud checking is slow or offline. Three microservices share an event-contract library.

`Java 17` `Spring Boot` `JMS` `ActiveMQ Artemis` `Docker`
